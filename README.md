# 🛍️ Zainab Store

**A modern, responsive e-commerce website built with HTML, CSS, and JavaScript.**

Zainab Store is a frontend web development project designed to provide a simple and user-friendly online shopping experience. Customers can browse products, search and filter the catalog, view product information, manage their shopping cart, complete checkout, and view their order history.

Product prices are displayed in Pakistani Rupees (PKR).

## ✨ Features

- **Product Catalog** — Browse products with images, descriptions, prices, and ratings.
- **Product Search** — Find products by name, category, or description.
- **Category Filtering** — Filter products by category.
- **Product Sorting** — Sort products by price or name.
- **Product Details** — View individual product information and add products to the cart.
- **Shopping Cart** — Add and remove products and update quantities.
- **Price Calculation** — Automatically calculate subtotals and delivery charges.
- **Checkout** — Enter customer and delivery information through a checkout form.
- **Order Management** — View order confirmations, order references, and previous orders.
- **Local Storage** — Retain cart and order information in the browser.
- **Responsive Design** — Use the website on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout, animations, and responsive design |
| JavaScript | Search, filtering, cart, checkout, and order functionality |
| Local Storage | Client-side persistence of cart and order data |

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. Visual Studio Code is recommended for editing the project.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Zainab-Mustafa14/ZainabStore.git
   ```

2. Navigate to the project directory:

   ```bash
   cd zainab-store
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No package installation or build process is required.

## 🛒 How to Use

1. Browse the available products on the homepage.
2. Search for products or filter them by category.
3. Select a product to view its details.
4. Add products to your shopping cart.
5. Adjust quantities or remove items as needed.
6. Proceed to checkout and enter the required customer information.
7. Place your order and view the confirmation.
8. Open the order management section to review previous orders.

## 💰 Currency and Delivery

- All product prices are displayed in Pakistani Rupees (PKR).
- Delivery charges are calculated during checkout.
- Orders that meet the configured minimum purchase amount qualify for free delivery.

Prices and delivery thresholds are sample values configured for this project and can be changed in the source code.

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, providing a usable shopping experience across desktop computers, tablets, and mobile devices.

## 🔒 Data and Security

This project uses browser Local Storage to retain cart and order information on the current device.

**Important:** Local Storage is not a secure database. This frontend implementation does not include server-side order processing, user authentication, or real payment processing. A production-ready store would require a backend API, database, server-side validation, and a payment gateway.
